# Pulsar

Android-приложение, которое помогает держать пульс в заданном коридоре. Читает пульс с
Bluetooth-датчика в фоне и сообщает, когда пульс выходит выше или ниже коридора:
вибрацией, которую можно различить на ощупь, и голосом в наушниках.

Приложение на стадии полевых испытаний.

## Возможности

- Работает с любым Bluetooth LE датчиком по стандартному профилю Heart Rate
  (нагрудные ремни, браслеты на руку, часы в режиме трансляции пульса).
- Три режима - Покой, Прогулка, Тренировка: у каждого свой коридор пульса, сигнал и
  вибрация. Коридоры прогулки и тренировки по
  умолчанию считаются от возраста.
- Автовыбор режима по пульсу и темпу шагов.
- Сигналы: разные виды вибрации для "выше", "ниже", "в коридоре" и "датчик потерян";
  своя нижняя граница во сне; тихие часы ночью.
- Экономия батареи во сне: пульс меряется минуту раз в заданный интервал, между
  замерами датчик отключён.
- Голос в наушниках: текущий пульс с заданным интервалом, по встряхиванию телефона и
  при выходе из коридора, вместе со скоростью.
- История с масштабом двумя пальцами, раскрашенная по коридору режима, который
  действовал в тот момент; скорость по шагомеру или GPS.
- Виджет, уведомление, Live Update / Now Bar на Android 16.
- Запись пульса в Health Connect (по желанию).
- Экспорт и импорт всей истории (CSV в gzip).
- Интерфейс и голос на 9 языках: английский, русский, немецкий, французский,
  испанский, итальянский, японский, корейский, китайский (упрощённый).

## Конфиденциальность

У приложения нет разрешения на доступ в интернет. История пульса, шаги и настройки
остаются на телефоне; наружу они попадают, только если включить Health Connect или
самому экспортировать историю.

## Требования

- Android 12 (API 31) или новее; для Live Update - Android 16.
- Bluetooth LE датчик пульса (Heart Rate Service 0x180D).
- Наушники для голосовых сообщений: через динамик телефона приложение не говорит.

## Сборка

Нужны JDK 17 и Android SDK. Путь к SDK - в `local.properties` (`sdk.dir=...`) или в
переменной `ANDROID_HOME`.

```bash
./gradlew :app:assembleDebug         # APK в app/build/outputs/apk/debug/
./gradlew :app:installDebug          # поставить на подключённый телефон
./gradlew :app:testDebugUnitTest     # unit-тесты, устройство не нужно
```

Debug-сборка дополнительно ведёт журнал испытаний (`no_backup/telemetry/`), по которому
подбираются пороги; в release-сборке его нет.

## Связь с другими приложениями

Pulsar отдаёт поминутный средний пульс на прогулках и тренировках через content
provider только для чтения (`content://com.puls.app.activity/minutes`). Доступ закрыт
signature-разрешением: читать могут только приложения, подписанные тем же ключом.

[Calorie](https://github.com/alexandrslesarenko/calorie), приложение для подсчёта калорий,
учитывает по этим данным прогулки и тренировки в суточной норме.

## Отказ от ответственности

Pulsar - не медицинское изделие, его нельзя использовать для диагностики или лечения.
Пульс с бытовых датчиков может быть неточным.
